# Security policy

**Please do not file public issues with passwords, API tokens, private keys, or exploitable vulnerability details.**

Report a security issue privately through GitHub's **Report a vulnerability** feature (Security > Advisories) if enabled. If private advisories are not available, open a minimal issue requesting a private reporting channel, without disclosing technical exploit details.

The project is an independent development environment; it is not a sandbox for hostile code. Because OpenCode can run commands on the mounted workspace, operators remain responsible for access control, least privilege, trusted dependencies and backups. Read the full [security guide](docs/SECURITY.md).
